# Compra Fácil — site oficial

Site institucional e página de links oficiais do Compra Fácil Delivery, criado para publicação na Vercel.

## Páginas

- `/` — apresentação completa do Compra Fácil;
- `/links` — página compacta para usar no link da bio.

## Desenvolvimento

```bash
npm install
npm run dev
```

O projeto é estático e não exige variáveis de ambiente.

## Prints do aplicativo

Os assets `app-home`, `app-categories`, `app-more-categories`,
`app-food-categories`, `app-benefits` e `app-rides` são cópias exatas dos arquivos
`1.png` a `6.png` de `compra_facil_sem_barras/` no projeto principal (945 × 1888).
Os dois celulares mostram `1.png` (início) e `2.png` (categorias), com proporção
original. Para sincronizar, execute `dart run tool/sync_store_screenshots.dart`
na raiz do projeto principal. Não use imagens de testes no lugar destes prints.
Ao atualizar uma imagem exibida, altere também a versão na URL do HTML para
invalidar o cache dos assets na Vercel.
